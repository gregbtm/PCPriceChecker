# Manual price alerts (free, no code needed)

Use these alongside the tracker while retailer scraping is unreliable. Set the target near **GBP 350** for 64GB (2x32GB) DDR5 SO-DIMM, or a price you accept for 48GB (2x24GB; N5 Air compatibility with 24GB modules is **Unverified**). The 2026-10-05 reference price was GBP 893.99 (Scan, 5200 MT/s kit). Site features change; check each site's current alert options. Nothing here was tested by the repo's author.

## What to buy (so alerts do not mislead)
DDR5 **SO-DIMM** (laptop size), **non-ECC**, a matched **2x32GB kit**, 5600 MT/s or slower. Not DDR4, not desktop DIMM, not CAMM2, not ECC/registered.

## Keywords
Use these on any site that supports keyword alerts or saved searches:

| Purpose | Keywords |
|---------|----------|
| Exact capacity | `DDR5 SODIMM 64GB`, `DDR5 SO-DIMM 2x32GB`, `64GB 2x32GB DDR5 SODIMM` |
| Brands that sell this | `Crucial DDR5 SODIMM`, `Kingston FURY Impact DDR5`, `Corsair Vengeance SODIMM DDR5`, `Patriot Viper DDR5 SODIMM`, `Teamgroup T-Force SODIMM DDR5` |
| Speed | `DDR5 5600 SODIMM`, `DDR5 5200 SODIMM` |
| Fallback | `DDR5 SODIMM 48GB`, `2x24GB DDR5 SODIMM` |
| Mini-PC angle | `64GB DDR5 SODIMM mini PC`, `laptop memory DDR5 64GB` |
| Exclusions (where supported) | `-DDR4 -ECC -"desktop" -"UDIMM" -"CAMM"` |

## Where
- **HotUKDeals:** keyword alerts for the terms above (free account); set a maximum price where the form allows.
- **eBay UK:** run a search such as `64GB 2x32GB DDR5 SODIMM`, filter to **Buy It Now**, **UK only**, then **Save this search** with email alerts. For used items, ask the seller for a photo of the module label.
- **Amazon UK:** use uk.camelcamelcamel.com. Search for a 64GB DDR5 SO-DIMM kit, add it, and set the target price. Check that the product is sold by Amazon or a reputable seller.
- **PCPartPicker UK:** price alerts on any 2x32GB DDR5 SODIMM kit it lists, where available.
- **Retailers:** use "notify me when in stock" on Scan, Ebuyer, Overclockers and Currys product pages when a kit is listed but unavailable. Scan's 5600 kit showed "Due 8th Oct" on 2026-10-05; a due date is not stock.
- **Other:** set a reminder to check Scan, Ebuyer and Overclockers weekly and write the price down; a short history helps judge when a real dip arrives.

## Judging a deal
- Compute GBP per GB: 893.99 / 64 = 13.97. Your GBP 350 target is 5.47 per GB.
- Treat anything far below the market (for example under GBP 2 per GB) as a likely scam until proven otherwise.
- eBay and marketplace prices exclude delivery; add it before comparing.
